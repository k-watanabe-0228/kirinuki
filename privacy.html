プライバシーポリシー

最終更新日：2026年10月16日

Clip Workbench（以下「本ツール」）は、開発者本人のみが利用する個人用ツールです。本ポリシーでは、本ツールが Google ユーザーデータをどのように取得・利用・保存・共有するかを説明します。

1. 取得するデータ

本ツールは、Google OAuth による認可を通じて、YouTube API サービスから以下のデータを取得します。

  • 認可したアカウントの YouTube チャンネル情報（チャンネル名、チャンネル ID）
  • チャンネル上の動画・再生リストの情報（タイトル、説明文、タグ、公開状態など）
  • 公開されている YouTube 動画のメタデータ（タイトル、公開日時、再生時間など）

2. データの利用目的

取得したデータは、切り抜き動画の制作・アップロード・管理の作業を行う目的にのみ利用します。広告、分析、プロファイリング、その他の目的には利用しません。

3. データの保存

認可トークンおよび取得したデータは、開発者本人の端末上にのみ保存します。外部のサーバーには送信しません。不要になったデータは随時削除します。

4. 第三者への共有

取得したデータを第三者に販売・提供・共有することはありません。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から取得した情報の利用および他のアプリへの転送は、限定使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに準拠します。

6. YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールを利用することにより、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いについては、Google プライバシーポリシーをご覧ください。

7. アクセス権の取り消し

本ツールに付与したアクセス権は、Google アカウントのセキュリティ設定からいつでも取り消せます。取り消した場合、本ツールは当該アカウントのデータにアクセスできなくなります。

8. お問い合わせ

本ポリシーに関するお問い合わせは、your-email@example.com までご連絡ください。
