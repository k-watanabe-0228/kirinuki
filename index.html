Clip Workbench

Clip Workbench は、開発者本人が YouTube の切り抜き動画の制作・管理作業を効率化するために作成した、個人利用専用のツールです。一般向けには提供していません。

主な機能

  • YouTube 上の配信・動画の情報（タイトル、公開日時、再生時間など）の取得
  • 自分の YouTube チャンネルへの切り抜き動画のアップロードと、タイトル・説明文・タグの管理
  • 自分のチャンネルの動画一覧・再生リストの管理

Google アカウントの利用について

本ツールは YouTube API サービスを利用しており、Google アカウントでのログインを通じて、開発者本人の YouTube チャンネルにのみアクセスします。取得したデータの扱いについては、プライバシーポリシーをご覧ください。
